# Contributing

1. Create a focused branch from `main`.
2. Make the smallest change that meets the request.
3. Run `npm run lint`, `npm run typecheck`, and `npm test`.
4. Check changed pages in a browser, including mobile layout when relevant.
5. Open a pull request describing the change and how it was verified.

Preserve existing website features unless their removal is explicitly requested.
Keep content changes separate from broad styling or dependency updates where practical.
Update the maintenance guide when the workflow changes.

Never include preview passwords, Cloudflare credentials, or other secrets in
commits, screenshots, or pull requests.

See [maintenance.md](maintenance.md) for the content map and deployment workflow.
